1. 本期摘要

  1. 月之暗面（Kimi）：10-24 发布 3 万亿级参数开源模型 Kimi K3.1 Pro，官方称其为「迄今能力最强的 3 万亿级参数模型」，智能指数逼近最强闭源模型，并同步推出高速版 Highspeed（来源：Kimi K3.1 Pro 发布报道，2026-10-24）——中国开源权重模型首次把与闭源前沿的智能差距压缩到约 3 分，标杆意义显著。
  2. OpenAI：10-26 发布中档模型 GPT-6.1 Terra，标准 API 定价输入 $1 / 输出 $5 每百万 token，为 GPT-5.6 Terra 与 GPT-6.1 Sol 的一半，聚焦计算机操作、视觉理解与日常办公自动化（来源：Dataconomy 报道，2026-10-27）——「以价换量」路线从旗舰延伸至中档模型。
  3. DeepSeek：10-17 发布 DeepSeek-V4.1-Flash-1017，在基准、运行速度与输出长度上实现「性能-成本的帕累托改进」，权重以 MIT 协议在 Hugging Face / ModelScope 开源，并同步向所有开发者开放自研 Search & Fetch API（来源：DeepSeek 官方公告，2026-10-17）——单次更新同时覆盖模型升级、开源与搜索基础设施。
  4. Google：旗舰 Gemini 4 Argon 于 10-13 在 Gemini API 正式可用（9-30 首发），推广价 $2/$10 每百万 token；同月 10-06 发布端侧多模态嵌入模型 EmbeddingGemma 2（来源：Gemini 4 Argon，2026-10-14；Gemma releases，2026-10-06）——旗舰落地与端侧轻量模型并行推进。
  5. Anthropic：10-07 发布 Claude Haiku 5.5，补齐 5.5 家族，官方称其为「迄今最快、最强的小型模型」，≤100K token 请求输入价降至 $0.10 每百万（来源：Claude release notes，2026-10-07）——小型模型以价换量承接高频与智能体任务。

3. 分厂商详情

3.1 Anthropic

3.1.1 模型发布与版本更新

  • Claude Haiku 5.5（10-07）：Claude 5.5 家族第三款、也是补齐版本（Opus 5.5 于 9-22、Sonnet 5.5 于 9-28 发布）。官方将其定位为「迄今最便宜、最快、最强的小型模型」，面向高吞吐、成本敏感任务（来源：Claude release notes，2026-10-07）。

3.1.2 能力与特性

  • Haiku 5.5 相对 Haiku 4.5 在编码、工具使用、computer use 与智能体（agentic）任务上有显著提升，官方称其为「首个可信的 Haiku 智能体」（来源：Claude Haiku 5.5 发布，2026-10-07；LLM-Stats 技术解析，2026-10-07）。

3.1.3 价格与开放策略

  • Haiku 5.5 定价：≤100K token 请求输入 $0.10、输出 $0.50 每百万 token；>100K 请求输入 $0.50、输出 $2.50（来源：NSTL 转载报道，2026-10-08）。社区跟踪报道称 Haiku 5.5 对齐 GPT-6 Luna 的定价（$0.10/$0.50）（来源：OrcaRouter 分析，2026-10-08）。
  • Max/Team 订阅每月 API 额度（10-07）：Max 和 Team 订阅现包含每月 API 额度，用于在 Claude Platform 上运行自有应用与智能体（来源：Claude release notes，2026-10-07）。

3.1.4 基准与评测

本期窗口内检索未发现 Anthropic 官方就 Haiku 5.5 发布的具体跑分数据；官方立场为「以更低成本承接高频任务」，具体基准数字以官网模型介绍页为准。

3.1.5 其他相关动态

  • Claude Duet 研究预览（10-21）：面向 Pro 和 Max 用户开放，Claude 作为主动式智能体运行于新应用。此属智能体产品（详见报告2），此处仅作模型生态相关动态记录（来源：Claude release notes，2026-10-21）。
  • 窗口内检索未发现 Anthropic 在融资、收购或高管讲话方面的可核实公开动态。

3.2 OpenAI

3.2.1 模型发布与版本更新

  • GPT-6 Sol / GPT-6 Luna 全量开放（10-07）：面向全部 ChatGPT 用户开放，替换 GPT-5.6 Sol 与 GPT-5.6 Luna（来源：KBS 报道，2026-10-08）。
  • GPT-5.5 退役（10-14）：官方「模型发布说明」确认 GPT-5.5 退役（来源：OpenAI Model Release Notes，2026-10-14）。
  • GPT-6.1 Terra 发布（10-26）：新增通用模型中档型号，API 模型 ID 为 gpt-6.1-terra，接替 GPT-5.6 Terra（来源：AWS 公告，2026-10-26；Dataconomy 报道，2026-10-27）。

3.2.2 能力与特性

  • GPT-6.1 Terra 主打计算机操作（computer use）、视觉理解、编程与日常办公任务，如读取屏幕上内容、点击应用、撰写回复提纲等（来源：DigitalToday 报道，2026-10-27）。知识截止日期为 2026-06-01，是 GPT-6 家族中最新的型号（来源：Dataconomy，2026-10-27）。

3.2.3 价格与开放策略

  • GPT-6.1 Terra API 定价：标准价为输入 $1 / 输出 $5 每百万 token（缓存输入 $0.05），较 GPT-5.6 Terra 与 GPT-6.1 Sol 低 50%（来源：Dataconomy，2026-10-27）。OpenAI 通用产品线由此形成四档：Luna（$0.10/$0.50）、Terra（$1/$5）、Sol（$2/$10）、Astra（$10/$50）。

3.2.4 基准与评测

  • Terminal-Bench 4.0：GPT-6.1 Terra 在 maximum 推理档下解决 50.3% 任务，对比 GPT-5.6 Terra 的 21.5%，提升超过一倍（来源：Digit 报道，2026-10-27；The Next Web，2026-10-26）。
  • OSWorld 2.1：官方称 Terra 在 medium effort 下超过 GPT-5.6 Terra 最佳成绩（来源：Omniakey 对比，2026-10-27）。

3.2.5 其他相关动态

  • GPT-6.1 Terra 同日（10-26）在 Amazon Bedrock 上正式可用（来源：AWS 公告，2026-10-26）。
  • 窗口内检索未发现 OpenAI 在融资、收购或高管讲话方面的可核实公开动态。

3.3 Google（Gemini）

3.3.1 模型发布与版本更新

  • Gemini 4 Argon（9-30 首发，10-13 GA）：10-13 起在 Gemini API 正式可用，定位面向真实世界软件工程、企业知识工作（法律、金融）与网络安全防御的旗舰模型（来源：Gemini 4 Argon 官方博客，2026-10-14）。
  • EmbeddingGemma 2（10-06）：740M 参数的开放权重多模态嵌入模型，将文本、代码、图像、视频、音频映射到统一嵌入空间，面向端侧/本地 RAG 检索（来源：Gemma releases，2026-10-06；TechRepublic 报道，2026-10-07）。

3.3.2 能力与特性

  • Argon 主打三个方向：real-world coding、enterprise knowledge work、cyber defense（来源：Gemini 4 Argon 官方博客，2026-10-14）。
  • EmbeddingGemma 2 是 Google 首个「原生多模态」开放权重嵌入模型，无需联网即可在手机、笔记本电脑本地处理多模态数据，数据不离开终端（来源：TechRepublic，2026-10-07）。

3.3.3 价格与开放策略

  • Argon API 推广价：每百万输入 token $2、输出 $10（缓存输入享 95% 折扣），优惠至 2026-11-30；此后输入标准价 $4、输出 $20（来源：Gemini 4 Argon 官方博客，2026-10-14）。
  • Gemini 应用分层调整（10-09 起）：免费档（无 Google AI 订阅）仅保留 Flash-Lite；Google AI Plus（约 $4.99/月）保留 Flash-Lite 与 Flash、失去 Pro；AI Pro（$19.99/月）与 AI Ultra 保留全部三档（来源：Google 支持文档，2026-10；TechRepublic，2026-10-06）。
  • EmbeddingGemma 2：开放权重模型（开放许可，具体条款以官方模型卡为准）（来源：Gemma releases，2026-10-06）。

3.3.4 基准与评测

  • DeepSWE v1.1：Gemini 4 Argon 得 77.9%，官方称刷新纪录，高于 Claude Opus 5.5 的 74.2% 与 GPT-6 Astra 的 74.1%（来源：IT之家，2026-10-01；The Next Web，2026-09-30）。
  • Vibe Code Bench：91.9%（来源：LLM-Stats 技术解析，2026-10-07）。
  • CWE-bench：68%，并列第一（来源：The Next Web，2026-09-30）。

3.3.5 其他相关动态

  • 窗口内检索未发现 Google/Google DeepMind 在 Gemma、Veo、Lyria、Gemini Robotics 等领域有覆盖窗口内（10-01~10-31）的其他可核实模型发布动态。

3.5 Kimi（月之暗面）

3.5.1 模型发布与版本更新

  • Kimi K3.1 Pro 发布（10-24）：K3.1 系列首个模型，官方称其为「迄今能力最强的 3 万亿级参数模型」，支持 100 万（1,048,576 token）上下文窗口。同日 10 月 24 日为「1024 程序员节」（来源：上海证券报/中国证券网，2026-10-24；北京日报，2026-10-26）。
  • Kimi K3.1 Pro Highspeed：同步推出的高速版，官方称「同等智能，输出速度约 2-3 倍」（来源：上海证券报，2026-10-24）。

3.5.2 能力与特性

  • K3.1 Pro 在代码、3D 创作、金融研究和其他长程 Agent 能力上提升明显；擅长参数化建模，可直接编写并运行 Blender、CAD 等专业工具脚本，端到端完成机械零件、建筑、多参数产品建模（来源：上海证券报，2026-10-24）。
  • 金融领域：官方称 K3.1 Pro 能端到端交付完整金融工作流，提供的案例包括英伟达财务模型、宁德时代投委会报告、量子计算行业研究等（来源：上海证券报，2026-10-24）。
  • 官网同步上线 3D Make 功能，支持在线预览与编辑、导出 3D 打印、视频或实况照片（来源：上海证券报，2026-10-24）。

3.5.3 价格与开放策略

  • Kimi K3.1 Pro API 定价：输入 $2.00 / 输出 $10.00 / 缓存输入 $0.20 每百万 token（同时提供人民币价 ¥13/¥68），与 GPT-6.1 Sol 相同，约为 Claude Opus 5.5 的一半（来源：Kimi API 定价页，2026-10-30；Simon Willison，2026-10-24）。
  • 开源权重：10-24 发布时定为开源模型，权重于 11 月在 Hugging Face 开放（模型卡显示约 2.8 万亿总参数、104B 激活参数，采用 Kimi K3.1 Pro License）。注：权重开放动作发生在覆盖窗口之外（11 月），此处仅作定位说明，不作为本期事件（来源：Hugging Face 模型卡，2026-11-06）。

3.5.4 基准与评测

  • Frontier Finance：K3.1 Pro 较 K3 进一步提升（来源：上海证券报，2026-10-24）。
